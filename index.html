介绍如下

HTML(HyperText Markup Language,超文本标记语言)是构建网页的标准标记语言,用一系列标签来描述文档的结构和语义,告诉浏览器哪部分是标题、段落、链接、图片或列表。它本身不是编程语言，不负责样式和交互(那分别交给 CSS 和 JavaScript),而是网页的骨架。一个 HTML 文档通常以 <!DOCTYPE html> 开头声明标准模式，用 <meta charset="UTF-8">保证文字正确解码，再由 <html>、<head&lgt;（元信息、标题、引入资源）和 <body>(可见内容)组成,通过标签嵌套形成层级结构。代码中的缩进和 <!-- 注释 --> 只服务于人的可读性,不影响渲染(少数保留空白的场景除外),而注释内容会随页面发送到浏览器、对用户可见,因此不能写敏感信息。总的来说,HTML 负责内容是什么、结构如何，与负责长什么样的 CSS 和负责怎么动的 JavaScript 一起，构成了现代 Web 的三大基石。
